## 📖 About This Project

This repository is part of the **CS50x Persian** initiative, created to make high-quality computer science education accessible to **Persian-speaking learners**.

The project provides Persian-language resources for **Harvard University's CS50 Web**, helping students learn web programming, web development, Python, Django, JavaScript, databases, user interfaces, testing, scalability, and security in their native language.

Through **CS50x Persian**, Persian-speaking students can access professionally translated educational content, course materials, exercises, and learning resources designed to make the CS50 Web curriculum easier to follow and understand.

Our goal is simple:

**To make world-class computer science education accessible to Persian speakers. ❤️**

---

## 🎓 About CS50 Web

**CS50's Web Programming with Python and JavaScript** is Harvard University's course designed to introduce students to modern web programming and web application development.

Throughout the course, students learn how to design and build web applications using technologies such as HTML, CSS, Python, Django, SQL, JavaScript, and more.

The Persian edition makes these concepts accessible to students who prefer learning web development and technical subjects in Persian.

---

## 📚 What You'll Learn

Throughout CS50 Web, you will learn:

* HTML
* CSS
* Git
* Python
* Django
* JavaScript
* Testing, CI/CD
* User Interfaces
* Scalability and Security
* SQL, Models, and Migrations

By the end of the course, you will have a strong foundation in modern web development and will be able to apply your skills to design, build, test, and deploy real-world web applications.
